Disentangling Denial-Feedback Side-Channels from Legitimate Agent Actions via Controlled Interventions

Section A: Problem Statement Threat Model

Tool-calling LLM agents autonomously query storage, APIs, and databases. When a runtime reference monitor denies an unauthorized tool call, the agent observes the denial event and error feedback. This creates an unintended side-channel—causality laundering (Chinaei, 2026)—where agents infer confidential state (existence, schema boundaries, sensitivity) and exfiltrate it via subsequent benign calls.

The Failure of Existing Heuristics (ARM Baseline Trade-offs):
  • Over-Approximation (High FP): ARM's IMMEDIATE_NEXT heuristic flags any post-denial call as tainted, crashing benign task completion from 100% to 14.3% (FPR 86.4% in EXP-002).
  • Under-Approximation (High FN): Lexical target-scoped filtering (SINK_SCOPED) prevents false alarms but fails against paraphrased, delayed, or multi-step laundering (ASR remains 75.0%–100%).

Target Affected: High-autonomy agents under zero-trust governance.
Core Engineering Gap: Inability to distinguish genuine denial-induced leakage from unrelated legitimate actions without crippling operational utility.

Section B: Research Review Foundations & Gaps

Primary Foundation: Mohammad Hossein Chinaei (April 2026, arXiv:2604.04035) formalized causality laundering and introduced the Agentic Reference Monitor (ARM) featuring a 5-level integrity lattice (Desc < Untrusted < Trusted < User < Sys), 4-layer policy pipeline (L1–L4), and hash-chained audits. Chinaei acknowledged ARM's temporal-adjacency heuristic cannot prove causality and lacked large-scale benign benchmarks.

Related Literature & Technical Limitations:

  • Information-Flow Control (FIDES, PCAS): Costa et al. (IEEE SaTML 2026) and Palumbo et al. (2026) compile declarative policies over observable data dependencies. Effective for direct flows, but blind to implicit knowledge inferred from negative denial outcomes.
  • Capability Isolation (CaMeL): Debenedetti et al. (2025) enforces planner/executor separation. However, if the planner sees denial feedback, structural token isolation fails to prevent inference.
  • Causal Diagnostics & Ablation: AgentSentry (Zhang 2026) and CausalArmor (Kim 2026) evaluate runtime re-execution and input ablation for prompt injection, but do not insulate runtime denial channels.
Identified Research Gap: Prior work either treats denials as silent terminal drops or relies on brittle temporal adjacency. No prior system isolates denial causality via structured counterfactual feedback intervention (C0 vs C1 vs C2).
Section C: Methodology & Empirical Evidence Evaluation

1. Controlled Counterfactual Interventions: Evaluates dual branches under identical tasks, seeds, initial states, and permissions: Branch A receives actual/informative feedback ($c_A$); Branch B receives neutralized/obscured feedback ($c_B$).

2. Three-Condition Protocol: C0 (Outcome-Obscured): Observation is byte-identical to a genuine missing resource ("No result is available"); C1 (Generic Denial): Discloses event only ("This request was denied"); C2 (Informative): Discloses non-sensitive coarse reason via versioned catalogue (cda-c2-reasons-v1). Contrast C0 vs C1 isolates event sensitivity; C1 vs C2 isolates reason sensitivity.

3. Canonical Lineage & Evidence Model: resolve_logical_source() maps synthetic runtime IDs to logical identities (logical::tool(args)) with SHA-256 content digests, preventing branch ID artifacts. EvidenceBasedAttributor outputs 4 verified classes without keyword heuristics: DENIAL_SENSITIVE, DENIAL_INDEPENDENT, AMBIGUOUS, and NOT_EVALUABLE.

Section D: Solution Framework Architecture

Implemented Core Architecture Modules:

  • ARMMonitor & Provenance Graph (src/monitor/): Evaluates L1–L4 with result mediation in concealing namespaces; maintains NetworkX graph with Call, Data, DeniedAction nodes and COUNTERFACTUAL edges.
  • Hash-Chained Audit Trail (M1): AuditLog records immutable SHA-256 records, separating authorization (ALLOW/DENY) from execution_status (EXECUTED/NOT_EXECUTED_DENIED/TOOL_ERROR).
  • Intervention Engine & Canonical Resolver (src/attribution/): Translates denials into C0/C1/C2 conditions and resolves branch IDs to invariant canonical sources (canonical.py).
  • Live Document Agent (src/live/): FastAPI SSE backend with local Ollama planner, security gateway, and interactive UI.

Note: Trace divergence indicates sensitivity under tested conditions, not formal mathematical proof of general causality.
